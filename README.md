# 胡麻將

巷仔口的台灣 16 張 3D 麻將。三缺一，就等你。

- 單人對三位街坊：柑仔店阿伯、檳榔攤阿珠姨、退休林老師，各有牌風、台詞與表情
- 教學提示：建議打哪張、聽哪幾張、危險牌警告
- 嗆聲貼圖、三個復古場景、五款台式牌背、合成音效
- P2P 多人連線：開房間、傳房號給朋友，空位由電腦補上

## 開發

```bash
npm install
npm run dev     # 本機開發（http://localhost:5178）
npm test        # 規則引擎與 AI 測試
npm run build   # 打包到 dist/
```

推到 `main` 會由 GitHub Actions 自動測試並部署到 GitHub Pages。

## 程式架構

| 資料夾 | 內容 |
|---|---|
| `src/core/` | 規則引擎：牌、向聽數、胡牌、台數、牌局流程（純邏輯） |
| `src/ai/` | 電腦對手與三種個性 |
| `src/game/` | 房主引擎、玩家介面、台詞、教學提示 |
| `src/net/` | PeerJS 連線、大廳、斷線重連 |
| `src/view3d/` | Three.js 牌桌、牌面、牌背、場景 |
| `src/ui/` | HTML 介面、頭像、音效、特效 |

所有牌面、頭像、場景與音效都由程式即時產生，沒有外部素材。
